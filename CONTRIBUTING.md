# Contributing

Thanks for taking the time to improve `tailwind-g-watch`.

## Local Setup

```bash
npm ci
npm test
```

## Pull Requests

- Keep changes focused.
- Include a short description of the behavior being changed.
- Run `npm test` before opening a pull request.
- Avoid unrelated dependency churn in feature or bug-fix pull requests.

## Release Notes

For user-facing changes, include a short note that can be copied into release notes.
